This guide walks you through creating and running your first automation on Script.it. You'll sign up, describe a workflow, and have the AI agent build and run it — no coding required. The whole process takes about five minutes.

<Steps>
  <Step title="Sign up for Script.it">
    Go to [app.script.it/login](https://app.script.it/login) and create a free account. No credit card is required.

    The first time you sign in, Script.it sets up your workspace and takes you on a short tour of the app: **Sessions**, where you talk to the agent, **Scripts**, where your saved workflows live, and the integrations that come already connected.

    <Tip>
      Your free account comes with included credits so you can build and run scripts straight away.
    </Tip>
  </Step>

  <Step title="Start a session">
    The tour ends with a starter prompt in the message box that asks the agent to interview you and suggest an automation. Send it, or replace it with your own idea.

    Any other time, click **New session** at the bottom of the sidebar, or press `Cmd+Shift+S` (`Ctrl+Shift+S` on Windows). A new session offers three starting points:

    - **Guide me to automation** — the agent asks about your work and suggests an automation.
    - **Teach me about Script.it** — the agent explains scripts and sessions and answers your questions.
    - **Templates for common Scripts** — browse ready-made workflows by role and start from one. You can also compare templates at [script.it/templates](https://script.it/templates).
  </Step>

  <Step title="Describe what you want to automate">
    Type what your automation should do in the message box and press `Enter`. Be as specific as you like — the agent handles the rest.

    For example:

    > "Every morning, fetch the top 5 headlines from Hacker News and send them to my Slack channel."

    The agent asks any questions it needs, then builds the script one block at a time, running each block as it goes. The script opens beside the chat so you can watch it take shape. A chip for it, marked **new**, appears above the message box; click it any time to open the script again.

    <Note>
      Keep chatting to refine the script. Ask the agent to add steps, change behavior, or explain what a block does. Use `@` to point at a specific script, block, or file. See [Agent chat](/sessions/chat).
    </Note>
  </Step>

  <Step title="Run the script and check the results">
    Ask the agent to run it — "Run it now" — or click **Run** on the script's page. **Run** opens the run in the message box so you can check the script's inputs, then click the run button to start it in a new session.

    Each block's results show on the script and in the chat as they finish. Files the run writes are in the session's **Session Files**: click the folder button above the message box to browse, preview, and download them. See [Session files](/sessions/files).

    If anything doesn't look right, describe the issue in chat and the agent will fix it.
  </Step>

  <Step title="Connect integrations if needed">
    Some integrations, such as AI models, web search, and email, come already connected, with no account or API key needed. If your script reads from or writes to one of your own accounts — Slack, Gmail, Notion, Google Sheets, and so on — you connect it once.

    The agent asks you to connect an integration when a script needs one. You can also connect integrations ahead of time from **Settings → Integrations**. If you work with teammates, you can share a connection or custom integration type with a workspace. See [Connecting integrations](/integrations/connecting).
  </Step>

  <Step title="Set up a trigger to automate it">
    Running a script by hand is useful for testing. Triggers let it run on its own:

    - **A schedule** — run on a recurring cadence, such as "every day at 9 AM", or on a cron expression.
    - **An app event** — run when something happens in a connected tool, like a new email or a new row in a spreadsheet.
    - **A webhook** — run when an external service, or a form on your own website, sends a request to a URL Script.it provides.

    To set one up, describe it in chat: "Run this every weekday morning at 8 AM." The agent creates the trigger for you.

    See [Triggers](/triggers/overview) for everything a trigger can watch for.
  </Step>
</Steps>
