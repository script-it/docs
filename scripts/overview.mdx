A script is the core unit of automation in Script.it. It's a series of steps, called blocks, that run in order. You describe what you want to automate in plain language, and the agent builds the script for you: it writes each block, runs it to check it works, and connects the pieces.

## What a script contains

| Part | What it is |
|---|---|
| **Name and description** | What the script does and when to use it |
| **Blocks** | The steps that run, in order. See [Blocks](/scripts/blocks). |
| **Inputs** | Values you set to change what a run does. See [Inputs and running](/scripts/inputs-and-running). |
| **Assets** | Files that stay with the script, such as templates and reference data. See [Assets](/scripts/assets). |
| **Triggers** | Rules that run the script automatically. See [Triggers](/triggers/overview). |
| **Agent Context** | How much of the script the agent reads on its own. See [Agent context](/scripts/agent-context). |

A script lives in a [workspace](/account/workspace). Everyone with access to the workspace sees the same script.

Script.it saves a version of the script at the end of every agent turn that changes it. To go back, open the script's **History** and choose **Restore version**, then **Restore this version**. See [Outlines, comments, and history](/scripts/outline-and-history#history).

Scripts are **reusable**. You can run the same script many times, in many sessions, without one run's results affecting another's.

## How the agent builds a script

When you describe an automation in a session, the agent works out the steps and builds the script one block at a time. It writes a block's code, runs the block, and fixes it until it works before moving on. You can watch the script take shape on its page as it goes.

Each block explains itself in plain language, so you can follow what it does without reading code. When you want a change, describe it in the chat or comment on the part you mean. See [Outlines, comments, and history](/scripts/outline-and-history).

<Tip>
  Feedback about how a script should behave on future runs belongs in the script. Say "ask me for the file next time" or "always check the sheet isn't empty first", and the agent changes the script so every later run does it.
</Tip>

## The script page

Open a script to see its page. The header holds:

- **Run**, to start a run, and the history button beside it.
- **Description**: what the script does and when to use it.
- **Agent Context**: how much of the script the agent reads on its own.
- **Last run**: shown when the last run ended early, with where and why.
- **Sessions**: the last session that ran or edited the script, and **View All**.
- **Triggers** and **Assets**, when the script has them.
- **Script inputs**: the values the next run uses.

Below the header, each block has a card with its inputs, its outline, and its latest outputs.

The bar at the top of the page holds **Publish** and the script's **⋮** menu: **Run in current session**, **Copy link to run script**, **Copy Script URL**, **Script Folder**, **Show script history**, and **Export Script**.

## What you can do with a script

<CardGroup cols={2}>
  <Card title="Run it" icon="play" href="/scripts/inputs-and-running">
    Set its inputs, run it or a single block, and follow the run.
  </Card>
  <Card title="Change it" icon="message-square" href="/scripts/outline-and-history">
    Comment on what should change, and restore an earlier version.
  </Card>
  <Card title="Hand a step to an Agent" icon="bot" href="/scripts/agents">
    Let an AI Agent do research, or answer other people for you.
  </Card>
  <Card title="Pause for approval" icon="hand" href="/scripts/approvals-and-waits">
    Ask before sending, or wait for a reply before continuing.
  </Card>
  <Card title="Run it automatically" icon="zap" href="/triggers/overview">
    On a schedule, on an app event, or from a webhook.
  </Card>
  <Card title="Publish it" icon="globe" href="/scripts/publishing">
    Share a read-only copy at a public link.
  </Card>
</CardGroup>

To work on a script with teammates, keep it in a shared [workspace](/account/workspace). To move a script elsewhere, choose **Export Script** from its **⋮** menu to download it. You can bring an exported script back in from **Settings → Account → Import Session or Script**.

## Where to start

To start from a ready-made idea, see [Templates](/scripts/templates). To build from scratch, open a new session and describe what you want to automate.
