Script.it is an AI-powered automation platform that lets you describe what you want to automate in plain English and have a working workflow built and running in minutes. You don't need to write code, wire up logic blocks, or manage infrastructure — you just tell the AI agent what you need.

You can build privately or collaborate in shared workspaces. Workspaces hold scripts, members, triggers, and shared integrations, so a team can run the same automations and reuse the same connected tools.

You don't have to be in the app to use your agent. You can message it by email, Slack, Microsoft Teams, Telegram, or WhatsApp, or call it from ChatGPT, Claude, and other AI assistants. See [Ways to reach your agent](/channels/overview).

## How it works

Every automation on Script.it follows the same pattern:

1. **Describe** — you type what you want to automate in the chat interface.
2. **The agent builds** — Script.it's AI agent creates a script with the right blocks and supporting code.
3. **Runs in a sandbox** — scripts run in a cloud environment that belongs to your account, kept separate from other accounts.
4. **Connects your tools** — scripts can read from and write to 600\+ integrations including Slack, Gmail, Notion, HubSpot, and more.

Organizations decide who can do what. Admins set roles and permissions, limit what each integration may do, and choose how much a session's agent is allowed to change. See [How access works](/governance/overview).

## Why Script.it

Most automation tools make you choose between rigid visual builders that break when your needs change, or fully autonomous AI agents that are hard to inspect or control. Script.it sits between these extremes: the AI does the heavy lifting, but every workflow is a readable script you can review, edit, and reuse.

## Key concepts

Here's a quick overview of the building blocks you'll encounter:

- **Workspaces** — collaboration spaces that hold scripts, members, triggers, and shared integrations.
- **Scripts** — Workflow definitions, each containing one or more blocks.
- **Blocks** — the individual steps in a script. Each block runs part of the automation or contains documentation.
- **Assets** — persistent files stored with a script, such as templates, reference data, or small state files.
- **Sessions** — chat conversations with the AI agent, each with its own isolated run files.
- **Triggers** — rules that run a script automatically: on a schedule, when something happens in a connected app, or when a webhook URL is called.
- **Integrations** — connected third-party services that your scripts can interact with.
- **Permissions** — organization roles, integration policies, and permission profiles that decide what people and agents can do.
- **Credits** — the usage-based currency that tracks AI and execution costs.

See [Core concepts](/core-concepts) for a full explanation of each.
