Every session has its own files, called **Session Files**. When a script runs, everything its blocks write — fetched data, reports, images, transformed datasets — lands there. Files you attach to a message land there too. Session Files are the session's `data_files/` folder.

## Open Session Files

Click the folder button above the message box, at the right (**Session Files**). The session's files open in the pane beside the chat. Click the button again to close them.

The pane shows a trail back to the session at the top. Inside it you can:

- **Switch the layout** between **Icons** and **List**. Script.it remembers your choice on this device.
- **Search** for a file by name, including inside subfolders.
- **Open a folder** to browse into it, and use the trail to go back up.

A session with no files yet shows **No files in session**.

You can also open a file from the chat: click a file chip in any message.

## What ends up in Session Files

| What | Where |
|---|---|
| Files a block writes | The block's output folder, such as `fetch/` or `summary/` |
| Files you attach to a message | `user-attachments/` |
| Files a trigger passes to the script | For example, `trigger_event.json` |
| Anything the agent saves for you in the session | Wherever the agent puts it |

<Note>
  Each time a block runs, Script.it normally empties its output folder first, so the folder holds that block's latest results. To keep a file across runs and sessions, ask the agent to save it as a [script asset](/scripts/assets).
</Note>

## Preview a file

Click a file to open it in the pane. Script.it shows most files in place, including Markdown, plain text and code, JSON, CSV, HTML, images, audio, video, PDF, and Word, PowerPoint and Excel files.

- **JSON** opens in an editor that can show tables, record pages, or boards.
- **HTML** renders as a page, with its scripts running in a sandbox.
- A file Script.it can't preview still lets you download it.

The file's header has **Edit file** for files you can edit in place, **Download file**, and **Reference file in chat**, which adds the file to your message as a chip.

## Work with files

Right-click a file or folder, or use its actions menu:

| Action | What it does |
|---|---|
| **Reference in chat** | Adds the file or folder to your message as a chip. |
| **Rename** | Renames it. |
| **Copy path** | Copies its path. |
| **Download** / **Download as .zip** | Downloads a file, or a folder as a `.zip` file. |
| **Delete** | Deletes it, after you confirm. |

**Rename** and **Delete** wait while the agent is working in the session (**Available when the agent finishes**).

### Upload files

Drag files from your computer onto Session Files. The pane reads **Drop files to upload to Session Files**. You can drop onto a folder to upload into it. The agent is told about the files you add or delete, so you can ask it to use them right away.

You can also attach files to a message, which saves them in `user-attachments/`. See [Agent chat](/sessions/chat#attach-files).

<Note>
  You can upload, rename, and delete files only in the session you have open. Another session's files are read-only from here.
</Note>

## Session files vs. script files

| | Session files | Script files |
|---|---|---|
| What they are | Outputs and attachments of this session | The script's definition, code, and [assets](/scripts/assets) |
| Where they live | The session's `data_files/` | The script's folder in its workspace |
| Who sees them | You, in this session | Everyone who can see the workspace |
| Kept over time | Yes, but each block's output folder holds only its latest run | Yes, with version history |

This separation keeps scripts reusable. You can run the same script many times, in different sessions, and the outputs of one run never mix with another.

## Download everything

To take a whole session with you, choose **Export** from the session's menu in the sidebar. You get a `.zip` file with the conversation and the session's files, which you can import again later. See [Managing sessions](/sessions/managing#export-and-import).

To download only the files, right-click the **Session Files** name at the top of the pane and choose **Download as .zip**. The same works for any folder inside it.
